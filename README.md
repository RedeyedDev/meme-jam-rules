# Meme Jam Rulebook

How [Meme Jam](https://t.me/meme_jam_bot/meme_jam_app), the meme basketball card game in Telegram, works: shots, combos, defense, clutch, game modes, collection, Free Throw, Season Pass and fair play.

**Open:** https://redeyeddev.github.io/meme-jam-rules/

- English by default; `?lang=ru` or `?lang=ua` switches the language (the switcher in the header remembers the choice).
- `?theme=light|dark` forces the theme; otherwise it follows the system.
- The "Try it" court is a practice toy with the real rules of a shot (combo, bench defenders, clutch). Its dice are local; in the game every roll comes from the match seed on the server.

One static `index.html`, no build step. Numbers on the page can be tuned while the game is in beta; the game itself always shows the current values and prices.

Raffle draws can be recomputed in the separate [raffle verifier](https://redeyeddev.github.io/meme-jam-raffle-verifier/).
